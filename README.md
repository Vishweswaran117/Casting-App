# 📽️ ProjectorCast – Ad-Free Video Casting App

<p align="center">
  **Your Movies. Your Screen. Zero Ads.**
</p>

ProjectorCast is an Android application that lets users cast movies and videos to compatible TVs and projectors without annoying advertisements. Enjoy your favourite entertainment on a bigger screen with a simple and clean experience.

---

## ✨ Features

- 📺 **Video Casting** – Cast supported videos to compatible TVs and projectors.
- 🎬 **Movie Entertainment** – Enjoy movies and videos on a bigger screen.
- 🚫 **100% Ad-Free** – No advertisements interrupting your entertainment.
- 📱 **Simple UI** – Clean and user-friendly interface.
- 🔌 **Device Connectivity** – Connect with supported casting devices.
- 🍿 **Big Screen Experience** – Enjoy your favourite content on a larger display.

## 🛠️ Technology Stack

- **Platform:** Android
- **IDE:** Android Studio

## 📲 Installation

### Install APK

1. Download the latest APK from the repository's Releases section.
2. Transfer it to your Android phone.
3. Open the APK file.
4. Allow installation from unknown sources if prompted.
5. Install and launch ProjectorCast.

### Build from Source

Clone the repository:

```bash
git clone https://github.com/Vishweswaran117/Casting-App.git
```

1. Open the project in Android Studio.
2. Wait for Gradle Sync to complete.
3. Connect your Android device or launch an emulator.
4. Click Run to build and launch the application.

## 📺 How to Use

1. Launch ProjectorCast.
2. Connect to a compatible TV or projector using the supported casting method.
3. Select your desired movie or video.
4. Start casting.
5. Enjoy uninterrupted entertainment!

*Casting compatibility depends on the receiving device and supported protocols.*
